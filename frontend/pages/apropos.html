À propos de cette plateforme

Plateforme de maintenance prédictive développée dans le cadre du stage OCP 2026. Conçue pour anticiper les pannes d'équipements industriels grâce à l'intelligence artificielle.

Modèle IA

Modèle de classification entraîné sur des données historiques de capteurs industriels pour prédire les risques de panne.

  • Accuracy : 84,5%
  • Recall (pannes) : 78%
  • F1-score : 76,6%
  • Seuil de décision : 0,39

Fonctionnalités

  • Prédiction en temps réel
  • Supervision des capteurs
  • Analytics avancés
  • Export CSV / PDF
  • Assistant IA
  • Alertes automatiques

Stack technique

  • Backend : Flask + Python
  • Frontend : Vanilla JS
  • Base de données : MySQL
  • Machine Learning : scikit-learn, joblib
  • Graphiques : Chart.js
